# v0.2.1 / v0.3.1 环境准备补丁

本次增加启动环境检测和简体中文 OCR 自动安装。红品检测判定逻辑未调整。此前 v0.2.0 / v0.3.0 的视频结果保留在原验证报告中，不能将旧视频结果表述为本次补丁重新完整播放的结果。

启动网页立即可用，环境准备在后台执行。环境就绪前禁止开始检测，不创建运行记录。已有中文 OCR 时不安装、不提权。缺失时通过 Windows UAC 发起安装，只安装 `Language.Basic~~~zh-CN~0.0.1.0` 和 `Language.OCR~~~zh-CN~0.0.1.0` 中尚未安装的组件。安装后再次检测系统引擎，并用对应 Python / Rust 实际调用接口验证。没有改变 PowerShell 执行策略。

授权取消、系统更新服务失败、需要重启、安装后引擎仍不可用时显示错误，并提供重试。程序不假报安装成功，安装器使用管理员权限，检测和网页进程使用普通权限。安装需要联网，系统可以要求重启。

验证范围：

- Python 26 项单元 / HTTP / 系统流程测试，Rust 7 项测试。
- PowerShell 流程使用模拟系统命令执行同一份安装代码：已有环境不安装、只检查不安装、Basic 后 OCR 安装、已有 Basic 跳过、授权取消、Windows Update 失败、需要重启、安装后检查失败。
- 本机已有中文 OCR，以真实 Windows 接口验证两版发布包的启动检查和引擎可用；环境准备及错误状态由共享网页展示。
- 桌面发布包的历史记录、人工复核、截图和端口冲突回归；分享包不含个人记录，解压后启动检查。

本机现有 OCR 保持完整，没有为测试卸载系统组件；缺失环境和安装失败路径使用模拟验证，尚未在全新缺少中文 OCR 的 Windows 电脑实际下载安装。UAC 是否允许、Windows Update 和网络策略仍由目标电脑决定。

旧版本目录保留。新桌面目录复制各自前一版本历史数据，SQLite 使用一致性备份保留已提交 WAL 数据和人工复核。分享压缩包包含运行文件及说明，不包含个人运行历史。
