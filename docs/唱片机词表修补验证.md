# 唱片机词表修补验证

日期：2026-10-04。根据用户要求只更新 JSON 排除词与验证，不重新打包、发布或修改原 Release。Python 和历史版本源码冻结。

反馈来自 v0.3.4。该版将唱片机红色图案连成候选，OCR 拼接文本包含“埕片机唱片机”；旧词表只有实验室、行星，没有唱片机，因此确认出红。v0.3.5 已在同一截图上按实际格子尺寸拒绝该候选。

在实际 v0.3.4 exe 中分别加载旧词表和追加唱片机的新词表，并对反馈截图运行 --panel：旧词表得到 red；新词表得到空 red，候选拒绝原因是排除词。证明修改 JSON 本身能修复该反馈，不依赖重新编译程序。

新词条使用完整唱片机，不泛化为唱片。公开测试验证正确及双 OCR 拼接名称被排除，航天导航仪、古董花瓶、古董茶壶和珍藏唱片不受默认新词影响，空数组仍可关闭排除。私有真实回归新增唱片机，三档缩放下确认不出红，同时保持陀螺仪正例、笔记本/柯恩币负例。

实际窗口测试在同一个后端进程里连续三次开始/停止，分别加载三份不同 JSON，运行记录保存的词表与文件一致。运行中改文件不会改写该运行的词表快照；下次开始读取新文件，无需退出后端进程。
