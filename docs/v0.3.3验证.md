# Rust v0.3.3 验证

日期：2026-10-01。只更新 Rust，Python v0.2.2 应用与历史快照冻结。

## 变化

- 一键生成单次运行反馈 ZIP：事件快照、截图、原始日志、参数、环境、人工复核与个人成绩；缺失文件有清单，无历史仍可导出环境。
- 个人最高爆率：同一次运行连续十个完整结算保险箱，遍历全部历史取最高；未完成和运行切换打断，start 不计箱数，并列取较新窗口。自动判定和复核独立。
- Rust 网页独立维护，增加直观指标、十箱结果格、历史筛选、截图弹窗、导出反馈、轻量过渡、窄屏布局与减少动画支持。
- 没有修改颜色、几何、OCR、模板或多帧检测判据。

## 实际结果

1. `cargo test --offline --locked --manifest-path native/Cargo.toml`：14 项全部通过。新增三项十箱测试覆盖滑动窗口、并列、跨运行、未完成、start 与不足十箱。
2. `tests/native_qa.py`：八张既有真实截图全部满足预期；原生 HTTP、空历史、非法路径、旧 JSONL 导入、截图读取和复核重启保留通过。此开发脚本引用归档检测样本，需要原有 Python 开发依赖；不属于发行版依赖。
3. `tests/native_features_qa.py`：启动实际 release exe，独立 ZIP 读取器检查 CRC、原截图和日志字节、复核、版本、无其他运行证据或 SQLite，验证重启保留、路径拒绝和无历史导出。1.2 MB 重复日志压缩后反馈包小于原数据三分之一。
4. 浏览器实际界面：页面跳转、出红筛选、截图放大与关闭、导出按钮下载均成功，下载 ZIP 49 个文件、CRC 完整；未发现页面控制台错误。最佳十箱链接实际筛选十条结算记录。
5. 临时窄屏测试：约 390 px 视口下页面宽度与可视宽度一致，无横向溢出；测试后恢复正常浏览器尺寸。
6. 新分享 ZIP 仅含 exe、red_filter.json、使用说明，无个人历史和工具链。干净解压后实际打包 exe 再次通过反馈与成绩端到端测试。

## 统计边界和反馈边界

自动判定为红但人工确认无红的历史记录，仍保留原判定并参与自动爆率；页面注明统计口径。人工复核不会追溯改变自动成绩。早期缺失运行起止元数据保持“未记录”，不造时间。

运行中导出先取得一致数据库快照，之后原始日志可能仍追加；原始日志可能有不完整末行。文本日志快速压缩，PNG 不重复压缩；分块读写，ZIP32 限制明确报错。导出按用户点击进行，不加入每帧检测流程。

没有重新完整播放此前四段视频，也没有在第二台 PC 实测。已验证本机 Windows 中文 OCR 和打包 exe；整体准确率、全部物品覆盖和所有分辨率仍不能从有限回归样本推断。
