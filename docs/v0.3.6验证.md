## 升级与源码

停止并退出旧程序，解压 v0.3.6 到新目录；复制完整 runs、个人 red_filter.json 和需要的 settings.json 可保留历史与设置。不改写历史自动判定或复核。新底部状态检查独立于右侧物品工作区，须保持游戏底部中央可见；任一命中观战/结算暂停，连续两次无提示恢复。

源码归档为 version/v0.3.6；原有各版本与冻结 Python 字节校验保持一致。当前主分支源码清单重新计算 SHA-256。发布标签必须指向对应源码提交，公开 main、Release 与下载包进行校验。
